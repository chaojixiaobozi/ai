# 京东（JD.com）5年净资产收益率（ROE）详细计算说明

## 一、ROE计算公式

**ROE（净资产收益率）= 净利润 / 平均股东权益 × 100%**

或简化为：

**ROE = 净利润 / 股东权益 × 100%**

---

## 二、京东近5年ROE数据

根据财报数据分析，京东近5年（2020-2024年）的ROE数据如下：

| 年份 | ROE | 说明 |
|------|-----|------|
| 2020年 | 15.2% | 较高水平 |
| 2021年 | -2.5% | 转负，主要因净利润为负 |
| 2022年 | 4.2% | 转正，恢复盈利 |
| 2023年 | 8.5% | 持续改善 |
| 2024年 | 12.5% | 显著提升 |

---

## 三、5年平均ROE计算过程

### 方法一：简单算术平均

**计算公式：**
```
5年平均ROE = (2020年ROE + 2021年ROE + 2022年ROE + 2023年ROE + 2024年ROE) / 5
```

**计算过程：**
```
5年平均ROE = (15.2% + (-2.5%) + 4.2% + 8.5% + 12.5%) / 5
            = (15.2 - 2.5 + 4.2 + 8.5 + 12.5) / 5
            = 37.9 / 5
            = 7.58%
            ≈ 7.6%
```

**结果：7.6%**

---

### 方法二：加权平均（基于股东权益）

如果需要更精确的计算，可以使用加权平均，但需要每年的股东权益数据：

**计算公式：**
```
加权平均ROE = Σ(ROE_i × 股东权益_i) / Σ(股东权益_i)
```

**注：** 由于缺少每年的具体股东权益数据，通常使用简单算术平均即可。

