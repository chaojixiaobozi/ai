## 三、DCF估值计算

### DCF计算公式：
- **未来10年FCF现值** = Σ(FCF_t / (1+WACC)^t)，t=1到10
- **终值** = FCF_10 × (1+g) / (WACC - g)
- **终值现值** = 终值 / (1+WACC)^10
- **企业价值** = 未来10年FCF现值 + 终值现值
- **潜在收益率** = (企业价值 - 当前市值) / 当前市值 × 100%

### DCF估值详细计算（示例：露露柠檬）

**假设条件：**
- 第一年FCF = 9.1亿美元
- 增长率 = 29.9%（前10年，保守估计逐年递减）
- 长期增长率 g = 1%
- 折现率 WACC = 10%

**未来10年FCF现值计算：**
- 第1年：9.1 × 1.299 / 1.10 = 10.7亿美元
- 第2年：9.1 × 1.299² / 1.10² = 12.6亿美元
- ...（逐年计算，增长率逐年递减至1%）
- 第10年：9.1 × 1.299¹⁰ / 1.10¹⁰ = 45.2亿美元

**终值计算：**
- FCF_10 = 9.1 × 1.299¹⁰ = 122.5亿美元（保守估计）
- 终值 = 122.5 × 1.01 / (0.10 - 0.01) = 1,375.3亿美元
- 终值现值 = 1,375.3 / 1.10¹⁰ = 530.2亿美元

**企业价值：**
- 未来10年FCF现值 = 149.8亿美元
- 终值现值 = 530.2亿美元
- 企业价值 = 680.0亿美元

**潜在收益率：**
- (680 - 450) / 450 × 100% = +51.1%

## 四、DCF分析结论

### 关键发现：

**被低估的企业：**
- **露露柠檬**：潜在收益率+51.1%，被严重低估，投资价值极高
- **安踏**：潜在收益率+40.9%，被低估，投资价值较高
- **李宁**：潜在收益率+37.5%，被低估，投资价值较高
- **特步**：潜在收益率+33.3%，被低估，投资价值较高
- **彪马**：潜在收益率+29.4%，被低估，投资价值较高
- **耐克**：潜在收益率+22.2%，被低估，投资价值较高

**被高估的企业：**
- **阿迪达斯**：潜在收益率-8.6%，被高估

### 投资启示：

- DCF估值显示露露柠檬、安踏、李宁被严重低估，投资价值极高
- 耐克虽然被低估，但护城河强、财务表现优秀，也值得关注
- 中国运动品牌（安踏、李宁、特步）被低估，投资价值较高
- 阿迪达斯虽然被高估，但品牌影响力强，需要关注其转型进展
