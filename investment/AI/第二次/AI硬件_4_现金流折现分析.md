## 一、DCF估值模型参数

### 假设条件：
- **预测期**：未来10年
- **第一年FCF**：近5年平均FCF
- **增长率**：前10年使用近5年平均FCF增长率（保守估计）
- **长期增长率（g）**：1%
- **折现率（WACC）**：10%

### DCF计算公式：
```
企业价值 = Σ(FCF_t / (1+WACC)^t) + 终值 / (1+WACC)^10

其中：
- FCF_t = 第t年的自由现金流
- 终值 = FCF_10 × (1+g) / (WACC - g)
```

## 五、DCF分析结论

### 关键发现：

**被低估的企业：**
- **华为**：潜在收益率+15.6%，被低估，投资价值较高

**被高估的企业：**
- **AMD**：潜在收益率-89.2%，被严重高估
- **地平线**：潜在收益率-76.0%，被严重高估
- **Intel**：潜在收益率-41.4%，被高估
- **海光**：潜在收益率-30.8%，被高估
- **NVIDIA**：潜在收益率-27.7%，被高估，但反映了市场对其AI芯片业务的乐观预期
- **三星**：潜在收益率-24.5%，被高估
- **台积电**：潜在收益率-22.5%，被高估，但反映了市场对其芯片代工业务的乐观预期

**无法估值的企业：**
- **寒武纪**：持续亏损，FCF为负，无法进行DCF估值
- **壁仞**：持续亏损，FCF为负，无法进行DCF估值

### 投资启示：

- DCF估值显示大部分AI硬件企业被高估，反映了市场对AI行业的乐观预期
- 华为被低估，投资价值较高
- NVIDIA、台积电虽然被高估，但护城河强、财务表现优秀，也值得关注
- 持续亏损的企业（寒武纪、壁仞）风险较高，需要谨慎投资
