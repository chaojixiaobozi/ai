## 三、DCF估值计算

### DCF计算公式：
- **未来10年FCF现值** = Σ(FCF_t / (1+WACC)^t)，t=1到10
- **终值** = FCF_10 × (1+g) / (WACC - g)
- **终值现值** = 终值 / (1+WACC)^10
- **企业价值** = 未来10年FCF现值 + 终值现值
- **潜在收益率** = (企业价值 - 当前市值) / 当前市值 × 100%

### DCF估值详细计算（示例：字节跳动）

**假设条件：**
- 第一年FCF = 188亿美元
- 增长率 = 27.6%（前10年）
- 长期增长率 g = 1%
- 折现率 WACC = 10%

**未来10年FCF现值计算：**
- 第1年：188 × 1.276 / 1.10 = 218.2亿美元
- 第2年：188 × 1.276² / 1.10² = 253.1亿美元
- ...（逐年计算）
- 第10年：188 × 1.276¹⁰ / 1.10¹⁰ = 1,245.8亿美元

**终值计算：**
- FCF_10 = 188 × 1.276¹⁰ = 3,232.5亿美元
- 终值 = 3,232.5 × 1.01 / (0.10 - 0.01) = 36,250.6亿美元
- 终值现值 = 36,250.6 / 1.10¹⁰ = 13,970.5亿美元

**企业价值：**
- 未来10年FCF现值 = 2,871.5亿美元
- 终值现值 = 13,970.5亿美元
- 企业价值 = 16,842.0亿美元

**注：** 由于字节跳动为私有公司，当前市值2,200亿美元为估算值，实际DCF估值可能更高。

- **Triller**：持续亏损，FCF为负，无法进行DCF估值
