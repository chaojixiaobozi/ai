# 全球保险行业Top10上市公司 - 入选企业排序（仅港股/美股/A股市场）

## 评分权重说明

- **潜在投资收益占比：40分**
  - 投资收益1和投资收益2的平均值作为评分依据
- **ROE分析占比：20分**
  - 近5年平均ROE和近3年平均ROE的平均值作为评分依据
- **销售收入增长占比：20分**
  - 近5年平均销售收入增长率和近3年平均销售收入增长率的平均值作为评分依据
- **当前负债率占比：20分**
  - 当前资产负债率越低得分越高（负债率越低越好）

---

## 评分计算方法

### 1. 潜在投资收益评分（40分）

计算公式：
- 平均投资收益 = (投资收益1 + 投资收益2) / 2
- 评分标准：
  - 超过100%：40分
  - 超过75%：35分
  - 超过50%：30分
  - 超过40%：25分
  - 超过30%：20分
  - 超过20%：15分
  - 高于10%：10分
  - 高于0%：5分
  - 低于0%：0分

### 2. ROE分析评分（20分）

计算公式：
- 平均ROE = (近5年平均ROE + 近3年平均ROE) / 2
- 评分标准：
  - 超过30%：20分
  - 超过20%：15分
  - 超过15%：10分
  - 超过10%：5分
  - 低于10%：0分

### 3. 销售收入增长评分（20分）

计算公式：
- 平均增长率 = (近5年平均增长率 + 近3年平均增长率) / 2
- 评分标准：
  - 超过40%：20分
  - 超过30%：15分
  - 超过20%：10分
  - 超过10%：5分
  - 低于10%：0分

### 4. 当前负债率评分（20分）

评分标准：
- 低于20%：20分
- 低于30%：15分
- 低于40%：10分
- 低于50%：5分
- 高于50%：0分

- **重要：仅保留港股/美股/A股市场的公司，已排除其他市场（如欧洲市场）的公司**
- **市场分布**：
  - 美股：UnitedHealth Group (UNH)、Progressive Corporation (PGR)、Chubb Limited (CB)
