# 全球存储内存行业Top10上市公司 - 入选企业排序

## 评分标准

根据要求，评分标准如下：

### 1. 潜在投资收益（40分）
- 超过100%：40分
- 超过75%：35分
- 超过50%：30分
- 超过40%：25分
- 超过30%：20分
- 超过20%：15分
- 高于10%：10分
- 低于10%：5分
- 低于0%：0分

**注：** 潜在投资收益取投资收益1和投资收益2中的较高值。

### 2. ROE分析（20分）
- 超过30%：20分
- 超过20%：15分
- 超过15%：10分
- 超过10%：5分
- 低于10%：0分

**注：** ROE取近5年平均ROE和近3年平均ROE中的较高值。

### 3. 销售收入增长率（20分）
- 超过40%：20分
- 超过30%：15分
- 超过20%：10分
- 超过10%：5分
- 低于10%：0分

**注：** 销售收入增长率取近5年平均增长率和近3年平均增长率中的较高值。

### 4. 当前负债率（20分）
- 低于20%：20分
- 低于30%：15分
- 低于40%：10分
- 低于50%：5分
- 高于50%：0分

**注：** 负债率 = 负债总额 / 总资产

---

## 评分计算公式

**总分 = 潜在投资收益得分 + ROE得分 + 销售收入增长率得分 + 当前负债率得分**
