# 指标定义与计算方法

## 一、指标定义

### 1. ROE（净资产收益率）
- **定义**：ROE = 净利润 / 平均股东权益
- **计算**：
  - 近5年平均ROE = (2020年ROE + 2021年ROE + 2022年ROE + 2023年ROE + 2024年ROE) / 5
  - 近3年平均ROE = (2022年ROE + 2023年ROE + 2024年ROE) / 3
- **数据来源**：公司年报中的利润表和资产负债表

### 2. 自由现金流（Free Cash Flow, FCF）
- **定义**：自由现金流 = 经营活动现金流 - 资本支出
- **计算**：
  - 近5年平均自由现金流 = (2020年FCF + 2021年FCF + 2022年FCF + 2023年FCF + 2024年FCF) / 5
  - 近3年平均自由现金流 = (2022年FCF + 2023年FCF + 2024年FCF) / 3
- **数据来源**：公司年报中的现金流量表

### 3. 潜在投资收益
- **投资收益1** = (近5年平均自由现金流 × 30 / 当前市值) - 1
- **投资收益2** = (近3年平均自由现金流 × 30 / 当前市值) - 1
- **说明**：该指标反映基于历史自由现金流，假设未来30年维持当前平均现金流水平，相对于当前市值的潜在收益率

### 4. 销售收入增长率
- **近5年销售收入增长率**：使用CAGR（年复合增长率）计算
  - CAGR = (2024年收入 / 2019年收入)^(1/5) - 1
- **近3年销售收入增长率**：
  - CAGR = (2024年收入 / 2021年收入)^(1/3) - 1
- **数据来源**：公司年报中的利润表（营业收入）

### 5. 资产负债率
- **定义**：资产负债率 = 负债总额 / 总资产
- **计算时点**：
  - 5年前资产负债率：2019年（或2020财年）的负债总额 / 总资产
  - 3年前资产负债率：2021年（或2022财年）的负债总额 / 总资产
  - 当前资产负债率：2024年（或最新财年）的负债总额 / 总资产
- **数据来源**：公司年报中的资产负债表

## 二、单位换算标准

- **1 Billion (B) = 10亿 = 1,000 Million (M)**
- **1 Million (M) = 100万**
- **1 Trillion (T) = 1,000 Billion = 1万亿**

### 常见错误预防
- 看到 "16.572B" 误理解为 "16.572亿美元"
- **正确理解**：16.572B = 16.572 × 10亿 = 165.72亿美元

### 数据记录要求
- 必须同时记录原始数据（英文单位）和换算数据（中文说明）
- 例如：16.572B（165.72亿美元）

## 三、筛选标准

### 初步筛选条件
1. **近5年平均ROE > 10%** 且 **近3年平均ROE > 10%**
2. **投资收益1 > 0** 且 **投资收益2 > 0**

### 放宽条件
- 如果入选企业少于3个，可以放宽ROE限制：
  - 允许近3年平均ROE > 10%（即使近5年平均ROE略低于10%）
  - 或允许近5年平均ROE > 10%（即使近3年平均ROE略低于10%）

## 四、评分体系（总分100分）

### 评分权重
1. **潜在投资收益**：40分
   - 投资收益1和投资收益2的平均值，按比例分配40分
2. **ROE分析**：20分
   - 近5年平均ROE和近3年平均ROE的平均值，按比例分配20分
3. **销售收入增长**：20分
   - 近5年增长率和近3年增长率的平均值，按比例分配20分
4. **当前负债率**：20分
   - 负债率越低得分越高（反向评分）

### 评分方法
- 各项指标在入选企业中进行排名
- 排名第1得满分，排名第2得80%分，排名第3得60%分（以此类推）
- 或按数值比例进行标准化评分

## 五、数据来源要求

### 官方数据来源
- **美国上市公司**：SEC官网的10-K或20-F文件
  - 网址：https://www.sec.gov/edgar/searchedgar/companysearch.html
- **中国上市公司**：
  - 上交所官网：http://www.sse.com.cn/
  - 深交所官网：http://www.szse.cn/
  - 公司官网投资者关系页面
- **其他地区上市公司**：公司官网投资者关系页面或当地交易所年报

### 注意事项
- **不要使用本地文件的数据**
- 所有数据必须从官方年报获取
- 数据需标注具体年份和来源
