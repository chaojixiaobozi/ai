# Docker镜像下载问题排查指南

## 问题分析

### 当前问题
- Docker已配置镜像源，但Jenkins镜像仍从Docker Hub下载
- 报错：`Get "https://registry-1.docker.io/v2/": net/http: request canceled while waiting for connection`
- 超时错误，说明网络连接有问题

### 根本原因
1. **镜像源配置可能未完全生效**
2. **Jenkins镜像可能需要特殊处理**
3. **网络连接问题**
4. **Docker Compose缓存问题**

## 解决方案

### 1. 验证镜像源配置

#### 检查当前配置
```bash
# 查看Docker daemon配置
docker info | grep -A 10 "Registry Mirrors"

# 检查daemon.json文件
cat /etc/docker/daemon.json
```

#### 重新配置镜像源
```bash
# 编辑daemon.json
sudo vim /etc/docker/daemon.json
```

确保配置如下：
```json
{
  "registry-mirrors": [
    "https://docker.1ms.run/",
    "https://docker.m.daocloud.io/",
    "https://dockerproxy.com/",
    "https://docker.mirrors.ustc.edu.cn/",
    "https://docker.nju.edu.cn/"
  ],
  "insecure-registries": [
    "192.168.100.186:5000",
    "192.168.100.186:5080",
    "127.0.0.0/8"
  ]
}
```

#### 重启Docker服务
```bash
# 重新加载配置
sudo systemctl daemon-reload

# 重启Docker服务
sudo systemctl restart docker

# 验证配置
docker info | grep -A 10 "Registry Mirrors"
```

### 2. 解决Jenkins镜像问题

#### 方案一：使用国内镜像源拉取Jenkins
```bash
# 先手动拉取Jenkins镜像
docker pull jenkins/jenkins:lts

# 或者使用国内镜像源
docker pull registry.cn-hangzhou.aliyuncs.com/library/jenkins:lts

# 给镜像打标签
docker tag registry.cn-hangzhou.aliyuncs.com/library/jenkins:lts jenkins-base
```

#### 方案二：修改docker-compose.yml使用具体镜像
```yaml
version: '3.8'

services:
  jenkins:
    image: jenkins/jenkins:lts  # 使用具体版本
    container_name: jenkins
    user: root
    # 其他配置保持不变...
```

#### 方案三：使用国内镜像仓库
```yaml
version: '3.8'

services:
  jenkins:
    image: registry.cn-hangzhou.aliyuncs.com/library/jenkins:lts
    container_name: jenkins
    user: root
    # 其他配置保持不变...
```

### 3. 网络问题排查

#### 检查网络连接
```bash
# 测试Docker Hub连接
curl -I https://registry-1.docker.io/v2/

# 测试镜像源连接
curl -I https://docker.mirrors.ustc.edu.cn/v2/

# 检查DNS解析
nslookup registry-1.docker.io
nslookup docker.mirrors.ustc.edu.cn
```

#### 配置DNS（如果需要）
```bash
# 编辑DNS配置
sudo vim /etc/resolv.conf

# 添加可靠的DNS服务器
nameserver 8.8.8.8
nameserver 114.114.114.114
```

### 4. 清理和重建

#### 清理Docker缓存
```bash
# 清理未使用的镜像
docker system prune -a

# 清理构建缓存
docker builder prune -a

# 清理网络
docker network prune
```

#### 重新构建服务
```bash
# 停止所有服务
docker-compose down

# 删除相关镜像
docker rmi jenkins-base

# 重新启动
docker-compose up -d
```

### 5. 高级解决方案

#### 使用代理（如果有代理服务器）
```bash
# 配置Docker代理
sudo mkdir -p /etc/systemd/system/docker.service.d
sudo vim /etc/systemd/system/docker.service.d/http-proxy.conf
```

添加代理配置：
```ini
[Service]
Environment="HTTP_PROXY=http://proxy.example.com:8080"
Environment="HTTPS_PROXY=http://proxy.example.com:8080"
Environment="NO_PROXY=localhost,127.0.0.1"
```

#### 使用本地镜像仓库
```bash
# 启动本地镜像仓库
docker run -d -p 5000:5000 --name registry registry:2

# 从其他源拉取镜像并推送到本地仓库
docker pull jenkins/jenkins:lts
docker tag jenkins/jenkins:lts localhost:5000/jenkins:lts
docker push localhost:5000/jenkins:lts
```

### 6. 完整的故障排除流程

#### 步骤1：验证基础配置
```bash
# 检查Docker状态
sudo systemctl status docker

# 检查镜像源配置
docker info | grep -A 10 "Registry Mirrors"

# 测试网络连接
ping -c 3 docker.mirrors.ustc.edu.cn
```

#### 步骤2：手动拉取镜像
```bash
# 尝试拉取Jenkins镜像
docker pull jenkins/jenkins:lts

# 如果失败，尝试其他镜像源
docker pull registry.cn-hangzhou.aliyuncs.com/library/jenkins:lts
```

#### 步骤3：修改compose文件
```yaml
version: '3.8'

services:
  jenkins:
    image: jenkins/jenkins:lts  # 使用官方镜像
    container_name: jenkins
    user: root
    ports:
      - "8080:8080"  # 添加端口映射
    volumes:
      - /home/dev/jenkins/data:/var/jenkins_home
      - /var/run/docker.sock:/var/run/docker.sock
      - /usr/bin/docker:/usr/bin/docker
      - /opt/maven:/opt/maven
      - /usr/bin/kubectl:/usr/bin/kubectl
      - /root/.kube:/root/.kube
    environment:
      - KUBECONFIG=/root/.kube/config
      - TZ=UTC
      - MAVEN_HOME=/opt/maven
      - JAVA_HOME=/opt/java/openjdk
      - PATH=/opt/java/openjdk/bin:/opt/maven/bin:$PATH
      - DOCKER_HOST=unix:///var/run/docker.sock
      - TMPDIR=/var/jenkins_home/tmp
      - ENKINS_TMP_DIR=/var/jenkins_home/tmp
      - JAVA_OPTS=-Djava.io.tmpdir=/var/jenkins_home/tmp
    restart: always
    networks:
      - shared-network

networks:
  shared-network:
    external: true
    name: nginx-proxy-network
```

#### 步骤4：重新启动服务
```bash
# 停止现有服务
docker-compose down

# 清理相关镜像
docker rmi jenkins-base 2>/dev/null || true

# 重新启动
docker-compose up -d
```

#### 监控脚本
```bash
#!/bin/bash
# 检查Docker服务状态
if ! systemctl is-active --quiet docker; then
    echo "Docker服务未运行，正在启动..."
    sudo systemctl start docker
fi

# 检查镜像源连接
for mirror in "https://docker.mirrors.ustc.edu.cn" "https://docker.1ms.run"; do
    if curl -s --connect-timeout 5 "$mirror" > /dev/null; then
        echo "镜像源 $mirror 连接正常"
    else
        echo "镜像源 $mirror 连接失败"
    fi
done
```

## 总结

这个问题的根本原因是网络连接和镜像源配置问题。通过以上步骤，您应该能够解决Jenkins镜像下载问题。建议按照步骤顺序执行，如果某个步骤失败，请检查相应的日志信息。
