# Docker镜像源配置指南

## 1. 查看当前Docker镜像地址

### 查看已拉取的镜像
```bash
# 查看本地所有镜像
docker images

# 查看镜像详细信息
docker inspect <镜像名:标签>

# 查看镜像的仓库地址
docker inspect <镜像名:标签> | grep -i repository
```

### 查看Docker配置
```bash
# 查看Docker daemon配置
docker info

# 查看Docker配置文件位置
docker system info | grep -i "Docker Root Dir"
```

## 2. 设置Docker镜像源

### 方法一：修改daemon.json配置文件（推荐）

#### Windows系统
1. 打开Docker Desktop
2. 点击设置图标 → Settings
3. 选择Docker Engine
4. 在JSON配置中添加镜像源：

```json
{
  "registry-mirrors": [
    "https://docker.mirrors.ustc.edu.cn",
    "https://hub-mirror.c.163.com",
    "https://mirror.baidubce.com",
    "https://ccr.ccs.tencentyun.com"
  ]
}
```

#### Linux/macOS系统
1. 创建或编辑daemon.json文件：
```bash
sudo mkdir -p /etc/docker
sudo vim /etc/docker/daemon.json
```

2. 添加镜像源配置：
```json
{
  "registry-mirrors": [
    "https://docker.mirrors.ustc.edu.cn",
    "https://hub-mirror.c.163.com",
    "https://mirror.baidubce.com",
    "https://ccr.ccs.tencentyun.com"
  ],
  "insecure-registries": [],
  "debug": false,
  "experimental": false
}
```

3. 重启Docker服务：
```bash
# Linux
sudo systemctl daemon-reload
sudo systemctl restart docker

# macOS
sudo launchctl stop com.docker.docker
sudo launchctl start com.docker.docker
```

### 方法二：使用Docker命令直接拉取

```bash
# 从指定镜像源拉取
docker pull registry.cn-hangzhou.aliyuncs.com/library/nginx:latest

# 给镜像打标签
docker tag registry.cn-hangzhou.aliyuncs.com/library/nginx:latest nginx:latest
```

## 4. 验证镜像源配置

### 检查配置是否生效
```bash
# 查看Docker daemon配置
docker info | grep -A 10 "Registry Mirrors"

# 测试拉取镜像
docker pull hello-world
```

### 查看镜像拉取来源
```bash
# 拉取时显示详细信息
docker pull --progress=plain nginx

# 查看镜像层信息
docker history nginx
```

## 5. 高级配置

### 配置私有镜像仓库
```json
{
  "registry-mirrors": [
    "https://docker.mirrors.ustc.edu.cn"
  ],
  "insecure-registries": [
    "192.168.1.100:5000",
    "myregistry.com:5000"
  ]
}
```

### 配置代理（如果需要）
```json
{
  "proxies": {
    "default": {
      "httpProxy": "http://proxy.example.com:8080",
      "httpsProxy": "http://proxy.example.com:8080",
      "noProxy": "localhost,127.0.0.1"
    }
  }
}
```

## 6. 故障排除

### 常见问题
1. **镜像拉取失败**
   - 检查网络连接
   - 验证镜像源地址是否正确
   - 尝试其他镜像源

2. **配置不生效**
   - 确保daemon.json格式正确
   - 重启Docker服务
   - 检查文件权限

3. **拉取速度慢**
   - 尝试不同的镜像源
   - 使用CDN加速的镜像源
   - 考虑使用本地镜像仓库

### 调试命令
```bash
# 查看Docker日志
docker system events

# 查看详细拉取过程
docker pull --debug nginx

# 清理未使用的镜像
docker system prune -a
```

## 7. 最佳实践

1. **多镜像源配置**：配置多个镜像源，Docker会自动选择最快的
2. **定期清理**：定期清理不需要的镜像以节省空间
3. **版本固定**：生产环境使用固定版本的镜像标签
4. **安全考虑**：避免使用不信任的镜像源
5. **监控使用**：监控镜像拉取频率和大小
